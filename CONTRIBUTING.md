# Contributing to EduGuard AI

Thank you for your interest in contributing to EduGuard AI!

## Team Members

This project was built by Team EduGuard for the IBM BoB AI Innovation Hackathon 2026 at CHARUSAT.

## How to Contribute

1. Fork the repository
2. Create a feature branch: `git checkout -b feature/your-feature-name`
3. Make your changes
4. Test thoroughly using the setup guide in `docs/setup-guide.md`
5. Submit a pull request with a clear description of your changes

## Code Style

- JavaScript: ES6+, clear variable names, comments for complex logic
- CSS: BEM-inspired class names, CSS variables for design tokens
- No external dependencies beyond Chart.js (CDN) and Google Fonts

## Reporting Issues

Open a GitHub Issue with:
- Clear description of the bug or feature request
- Steps to reproduce (for bugs)
- Expected vs actual behaviour
- Browser and OS version

## IBM Bob Integration

When contributing AI features, ensure IBM Bob is genuinely integrated (not just mentioned). Reference `bob.ibm.com/docs/ide` for the latest Bob capabilities.
